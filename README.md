✨ GlowAura - 3D Luxury Skincare DisplayGlowAura is an interactive, web-based 3D product showcase for high-end luxury skincare products. Designed with Three.js and styled using Tailwind CSS, this web application delivers an immersive, interactive, and premium shopping experience.🌟 Key FeaturesInteractive 3D Render: Real-time 3D rendering of luxury serum bottles using procedural glass materials, refraction, metallic finishes, and soft reflections.Dynamic Product Switcher: Toggle between different product formulations (e.g., Radiance Serum, Hydra-Luxe Elixir, and Night Renewal Oil), each featuring customized lighting, liquid colors, and details.Customization Controls: Adjust rotation, zoom level, dynamic lighting angle, and wireframe views in real time.360° Studio Controls: Orbit controls allowing users to rotate, tilt, and zoom to inspect fine product details.Responsive & Modern UI: Fully responsive design built with Tailwind CSS, supporting dark/light UI modes, product specs overlays, and add-to-cart interactions.Single-File Architecture: Built as a self-contained, lightweight, and performant web application with no complex build steps required.🛠️ Tech StackHTML5 & JavaScript (ES6+): Core application markup and interactive logic.Three.js: 3D rendering engine, materials, lights, and orbit controls.Tailwind CSS: Utility-first CSS framework for modern styling and layout design.Lucide Icons: Clean UI iconography.🚀 Getting StartedPrerequisitesAll dependencies (Three.js, Tailwind CSS, Lucide Icons) are included via fast CDN references. No local runtime or npm installation is necessary.Running LocallyClone or download the repository:git clone https://github.com/your-username/glowaura-skincare-3d.git
Navigate to the project directory:cd glowaura-skincare-3d
Open index.html in any modern web browser:Double-click index.html, orUse a local dev server such as VS Code's Live Server extension or Python's HTTP server:python -m http.server 8000
